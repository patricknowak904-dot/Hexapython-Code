# Épisode 1 : Qu'est-ce qu'un modèle d'IA ?

Expliquer ce qu'est un modèle d'IA (une fonction dont les paramètres sont appris à partir de données), distinguer apprentissage supervisé et non supervisé, et entraîner en Python pur une régression linéaire qui prédit le prix d'un appartement.

## Ce que tu apprends

- Modèle = fonction paramétrée
- Données d'entraînement et de test
- Fonction de coût (MSE)
- Régression linéaire
- Apprentissage supervisé vs non supervisé

## Le projet

Projet Python pur (aucune bibliothèque externe) qui accompagne l'épisode 1 de la saison « L'IA de A à Z » d'HexaPython. Il construit pas à pas un modèle d'IA, c'est-à-dire une fonction paramétrée qui prédit le prix d'un appartement. Le parcours couvre la fonction de coût MSE, le découpage entraînement/test, la recherche par force brute, la formule des moindres carrés de Legendre et la comparaison avec un modèle de référence. Il montre aussi l'apprentissage non supervisé, les pièges classiques sur les données et la solution du défi à trois boutons.

## Contenu du dossier

- `projet/` : le programme complet de l'épisode, avec sa sortie dans `projet/sortie-attendue.txt`
- `exemples/` : un fichier par exemple montré dans la vidéo, avec la sortie attendue en commentaire
- `defis/` : les défis proposés dans l'épisode

## Lancer le projet

Python 3.11 ou plus récent est recommandé.

```bash
cd projet
python main.py
```
